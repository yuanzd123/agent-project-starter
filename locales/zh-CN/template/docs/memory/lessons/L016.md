# L016 · 缓存和后台进程也是构建输入

状态、检索标签与复核日期以 [登记表](../lessons.json) 为准。

- **适用 / 触发**：同修订结果不一致、旧页面不更新或构建出现意外文件。
- **原因**：遗留进程可在构建中重新生成文件，旧缓存也可能掩盖变更。
- **原则**：隔离任务的缓存、产物与 watcher，怀疑环境污染时先举证，不盲删全局资源。
- **处理**：记录本任务进程与产物归属，使用可重复构建目录，必要时精准停止与重建。
- **验证**：比较干净隔离构建和实际产物；确认没有其他进程写入同目录。
- **失效 / 复核条件**：构建器、缓存键或进程生命周期变更时。

来源为经过脱敏和重写的历史工程经验，见 [导入评审](../IMPORT_REVIEW.md)。具体技术实现必须在新项目中核实。
