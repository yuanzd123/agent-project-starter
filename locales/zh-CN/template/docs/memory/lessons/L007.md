# L007 · 按风险验证实际执行路径

状态、检索标签与复核日期以 [登记表](../lessons.json) 为准。

- **适用 / 触发**：新增集成、改 schema 或交付用户可见行为。
- **原因**：测试替身可能绕过真正失败的路径。
- **原则**：静态检查和 mock 只证明对应层级；外部依赖、真实配置和用户交互需要适当的运行证据。
- **处理**：选择最小但真实的受控验收；无权限或设备时保留未验证范围。
- **验证**：检查输入到可观察结果的闭环，确认测试走了真实依赖路径。
- **失效 / 复核条件**：外部服务或产品路径改变；不要求每个小改动都运行完整生产验收。

来源为经过脱敏和重写的历史工程经验，见 [导入评审](../IMPORT_REVIEW.md)。具体技术实现必须在新项目中核实。
