# L013 · 技术经验注明版本与失效条件

状态、检索标签与复核日期以 [登记表](../lessons.json) 为准。

- **适用 / 触发**：升级依赖、换机器、迁移项目或导入 lessons。
- **原因**：历史缺陷可能修复，旧参数和固定路径会制造新问题。
- **原则**：保留故障机制，复核具体版本命令与 workaround；旧经验不是永久真理。
- **处理**：查看实际版本、官方说明和最小复现；证据不足的做 candidate。
- **验证**：对当前目标复现问题或验证其已修复，并记录可移除条件。
- **失效 / 复核条件**：任何依赖、平台或行为变化均触发复核。

来源为经过脱敏和重写的历史工程经验，见 [导入评审](../IMPORT_REVIEW.md)。具体技术实现必须在新项目中核实。
