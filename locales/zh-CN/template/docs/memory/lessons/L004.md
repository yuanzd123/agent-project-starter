# L004 · 测试资源隔离到实际身份

状态、检索标签与复核日期以 [登记表](../lessons.json) 为准。

- **适用 / 触发**：dev、seed、集成测试、时钟模拟或 SDK 初始化。
- **原因**：配置加载和 SDK 默认行为可能访问真实数据或本机登录缓存。
- **原则**：启动本地命令前确认实际数据库、账号、存储和 SDK 配置；测试不继承生产副作用。
- **处理**：使用专用资源，核对最终解析目标；敏感值放外部配置且不打印。
- **验证**：用隔离环境验证，必要时检查网络目标和测试前后的资源变化。
- **失效 / 复核条件**：新 SDK、环境变量加载器或执行入口改变时。

来源为经过脱敏和重写的历史工程经验，见 [导入评审](../IMPORT_REVIEW.md)。具体技术实现必须在新项目中核实。
