# L014 · 批量编辑保护不应变化的内容

状态、检索标签与复核日期以 [登记表](../lessons.json) 为准。

- **适用 / 触发**：批量文案、重命名、格式整理或迁移。
- **原因**：人工抽看容易漏改动，旧快照也可能覆盖其他人的新工作。
- **原则**：用数值、结构和行为不变量检查大批量修改，差异先诊断归属再处理。
- **处理**：建立任务范围内的基线和允许变化集合；不将所有漂移自动视为污染。
- **验证**：比较关键数值、标识、结构或行为，并逐项审阅异常。
- **失效 / 复核条件**：本任务本来就需要修改这些不变量时重新定义允许集合。

来源为经过脱敏和重写的历史工程经验，见 [导入评审](../IMPORT_REVIEW.md)。具体技术实现必须在新项目中核实。
