# L012 · 交互与链接检查最终呈现

状态、检索标签与复核日期以 [登记表](../lessons.json) 为准。

- **适用 / 触发**：按钮、卡片、锚点或 CMS 页面变化。
- **原因**：覆盖层、hover 层叠和备用组件会让源码看似正确却无法操作。
- **原则**：控件应有真实语义和行为，验证最终页面目标以及键盘、鼠标和触屏关键交互。
- **处理**：使用合适的 link/button，检查实际渲染路径和可访问名称。
- **验证**：对变更路径做真实点击和键盘检查；页内目标存在且唯一，落点可见。
- **失效 / 复核条件**：前端路由或渲染模式改变时调整检查，不强制所有应用采用静态 HTML。

来源为经过脱敏和重写的历史工程经验，见 [导入评审](../IMPORT_REVIEW.md)。具体技术实现必须在新项目中核实。
