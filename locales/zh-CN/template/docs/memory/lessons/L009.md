# L009 · 数据修复先确认权威值与草稿

状态、检索标签与复核日期以 [登记表](../lessons.json) 为准。

- **适用 / 触发**：seed、补空、移除渲染覆盖或修复看似回滚的页面。
- **原因**：旧代码值可能遮蔽库中数据，默认读取也可能看不到草稿。
- **原则**：修改内容前找真实数据源，保留草稿与运营编辑，按字段和版本处理迁移。
- **处理**：先读取当前值和草稿并诊断；未知不等于空，避免整页或整库覆盖。
- **验证**：读回权威数据并检查最终渲染；冲突时重算变更，不覆盖新版本。
- **失效 / 复核条件**：权威来源或 CMS 发布机制更换时重新验证。

来源为经过脱敏和重写的历史工程经验，见 [导入评审](../IMPORT_REVIEW.md)。具体技术实现必须在新项目中核实。
