# L006 · 验证入口不能吞掉失败

状态、检索标签与复核日期以 [登记表](../lessons.json) 为准。

- **适用 / 触发**：实现任务运行器、CI、shell 包装或日志管道。
- **原因**：条件调用和管道会改变错误传播，最后一个成功步骤可能掩盖前面失败。
- **原则**：必要检查失败、超时、命令缺失或配置缺失，都不能成为 PASS。
- **处理**：显式处理退出状态，缺失与失败分别报告；没有测试就写未配置。
- **验证**：让早期命令故意失败、晚期命令成功，断言总入口非零并停止；验证缺失命令。
- **失效 / 复核条件**：运行器换语言、shell 或任务系统时重测。

来源为经过脱敏和重写的历史工程经验，见 [导入评审](../IMPORT_REVIEW.md)。具体技术实现必须在新项目中核实。
