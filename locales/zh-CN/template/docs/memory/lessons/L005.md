# L005 · 任务改动和共享资源分别隔离

状态、检索标签与复核日期以 [登记表](../lessons.json) 为准。

- **适用 / 触发**：多人或多个会话并行工作。
- **原因**：宽泛暂存和共享文件修改会带入半成品；全局阻塞又会迫使无关任务合并。
- **原则**：保留无关改动，精确暂存；并行编辑用独立工作树，共享引用和环境单独协调。
- **处理**：先查归属，只操作本任务路径；必要时对同一发布目标串行，不清理别人资源。
- **验证**：审阅实际 staged diff 和最终提交范围，不只看提交消息。
- **失效 / 复核条件**：单工作树已有共同编辑协议，或任务明确要求全局整理时重新划分范围。

来源为经过脱敏和重写的历史工程经验，见 [导入评审](../IMPORT_REVIEW.md)。具体技术实现必须在新项目中核实。
