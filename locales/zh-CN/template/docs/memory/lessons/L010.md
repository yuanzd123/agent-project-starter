# L010 · 验证写入真正持久化

状态、检索标签与复核日期以 [登记表](../lessons.json) 为准。

- **适用 / 触发**：数据库事务、余额、库存、订单或关键状态更新。
- **原因**：连接内读回和内存对象可能掩盖提交失败。
- **原则**：关键写入用独立连接或事务读回，并测试并发、失败和回滚，不只相信返回对象。
- **处理**：传播提交错误，明确事务边界和重试条件，避免在不确定状态上盲重试。
- **验证**：模拟提交失败与并发，用新连接或重启后的存储状态验收。
- **失效 / 复核条件**：驱动、事务层或隔离级别升级时；不沿用旧驱动补丁作为通用解法。

来源为经过脱敏和重写的历史工程经验，见 [导入评审](../IMPORT_REVIEW.md)。具体技术实现必须在新项目中核实。
