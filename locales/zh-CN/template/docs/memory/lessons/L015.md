# L015 · 时间测试固定时钟与业务时区

状态、检索标签与复核日期以 [登记表](../lessons.json) 为准。

- **适用 / 触发**：预约、期限、账期、缓存或过期逻辑。
- **原因**：机器时区和真实当前时间会让同一测试偶发成功或失败。
- **原则**：显式固定时钟与业务时区，覆盖跨日和夏令时等边界，避免靠等时间或跳过测试解决。
- **处理**：优先注入时钟，在隔离依赖中模拟时间，不改变真实凭据的有效性判断。
- **验证**：固定边界输入，验证当地日期和持续时长；确认不触发真实 SDK 刷新。
- **失效 / 复核条件**：时区规则或业务计时定义变化时。

来源为经过脱敏和重写的历史工程经验，见 [导入评审](../IMPORT_REVIEW.md)。具体技术实现必须在新项目中核实。
