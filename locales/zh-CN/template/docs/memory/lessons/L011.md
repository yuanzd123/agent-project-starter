# L011 · 权限与租户边界不能靠提权绕过

状态、检索标签与复核日期以 [登记表](../lessons.json) 为准。

- **适用 / 触发**：权限报错、后台功能或多租户行为。
- **原因**：提权可能让功能恢复，却暴露不应访问的数据；租户参数硬编码会串用。
- **原则**：修访问规则而非默认提升角色，租户专属参数与公共能力分开维护。
- **处理**：保持预期最小角色，修规则；按稳定租户身份解析配置。
- **验证**：同时测试允许、拒绝、跨租户与未认证路径。
- **失效 / 复核条件**：角色模型或租户边界发生批准的产品变化时。

来源为经过脱敏和重写的历史工程经验，见 [导入评审](../IMPORT_REVIEW.md)。具体技术实现必须在新项目中核实。
