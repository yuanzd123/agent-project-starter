# L002 · 证据分层，不把旧状态当成今天

状态、检索标签与复核日期以 [登记表](../lessons.json) 为准。

- **适用 / 触发**：汇报进展、交接或恢复旧会话。
- **原因**：旧待办或代码合入记录不能证明当前环境状态。
- **原则**：实现、检查通过、部署、启用和真实使用分别举证；记忆与当前证据冲突时先核实。
- **处理**：核对相关源码、任务结果和环境；未知项明确写未验证，不靠修改日期伪装更新。
- **验证**：逐条将状态断言对应到合适证据；远端不可读时记录信息截至时间。
- **失效 / 复核条件**：证据对应版本、环境或用户决定发生变化。

来源为经过脱敏和重写的历史工程经验，见 [导入评审](../IMPORT_REVIEW.md)。具体技术实现必须在新项目中核实。
