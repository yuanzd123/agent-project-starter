# L008 · 配置名称不是发布目标身份

状态、检索标签与复核日期以 [登记表](../lessons.json) 为准。

- **适用 / 触发**：构建、预览、发布、回滚或域名配置。
- **原因**：别名、配置、候选和当前运行版本是不同对象。
- **原则**：核对实际账号、项目、环境、候选修订和运行入口，不能从配置文件名或构建成功推断上线。
- **处理**：在受控流程里显式验证目标和修订；复用证据时核对其绑定对象。
- **验证**：验证最终入口指向目标版本；若约束要求其他资源不变，比较实际资源配置。
- **失效 / 复核条件**：提供商、发布拓扑或参数语义改变时。

来源为经过脱敏和重写的历史工程经验，见 [导入评审](../IMPORT_REVIEW.md)。具体技术实现必须在新项目中核实。
