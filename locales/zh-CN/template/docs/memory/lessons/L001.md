# L001 · 一个事实只维护一个权威来源

状态、检索标签与复核日期以 [登记表](../lessons.json) 为准。

- **适用 / 触发**：多个 agent、工作树或入口重复记录同一个决定。
- **原因**：副本独立更新，会让旧约束复活或遗漏新决定。
- **原则**：指令、当前状态和长期经验分层维护，工具入口引用同一正文，避免复制后互相漂移。
- **处理**：修改唯一正文，其他位置只留链接；当前状态不塞进导航。
- **验证**：检查入口链接、重复记录和 agent 实际加载的文件。
- **失效 / 复核条件**：新协作方式需要多份独立状态时，重新定义归属与合并规则。

来源为经过脱敏和重写的历史工程经验，见 [导入评审](../IMPORT_REVIEW.md)。具体技术实现必须在新项目中核实。
