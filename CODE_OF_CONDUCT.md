# Community code of conduct

We want people with different experience levels and backgrounds to be able to use, question, and improve this project.

- Be respectful and specific. Critique code and ideas, not people.
- Welcome questions and accept corrections. Explain tradeoffs without dismissing newcomers.
- Do not harass, threaten, discriminate, impersonate, or publish another person's private information.
- Do not spam discussions, solicit reciprocal stars, or misrepresent adoption or test results.

This applies to project issues, pull requests, discussions, and other spaces maintained for the project.

For a concern that can be described without exposing private details, contact the maintainer through a project issue and request a private follow-up. For a confidential report, use the contact channel linked from [the maintainer's public profile](https://github.com/yuanzd123); do not post sensitive details publicly. Security vulnerabilities have a separate [reporting process](SECURITY.md).

Maintainers may remove harmful content, request a correction, restrict participation, or ban repeated or serious violations. They will consider context and protect private information while handling reports. These standards apply to maintainers as well as contributors.
