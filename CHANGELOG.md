## 0.1.0 - 2026-10-15

First public release.

- Standalone English and Simplified Chinese project-initialization prompts.
- Python standard-library harness with explicit projects, required checks, dry-run, timeouts, and nonzero failure propagation.
- Shared memory with bounded task briefs, generated index, review dates, and lesson retirement.
- Sixteen distilled principles, three candidate categories, and two retired or superseded records.
- Conflict-aware bootstrap with English and Chinese template selection.
- Disposable offline demo, regression tests, and a cross-platform CI matrix.

This is an early release. Application checks are intentionally unconfigured until adapted to the target project. The runner is not a sandbox, and the memory checker does not certify factual accuracy.
