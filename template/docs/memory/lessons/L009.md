# L009 · Find authoritative data and preserve drafts

Status, tags, and review dates live in the [registry](../lessons.json).

- **Scope / trigger**: Seeding, filling empty fields, removing render-time overrides, or investigating apparent rollbacks.
- **Cause**: Code overrides can hide stored values, and default queries may not include drafts.
- **Principle**: Before content repair, identify the real data authority, preserve drafts and operational edits, and migrate by field and version.
- **Action**: Read current values and drafts before diagnosing. Unknown is not empty; avoid whole-page or whole-database replacement.
- **Validation**: Read back authoritative data and inspect the final output. Recompute changes on conflict rather than overwriting newer versions.
- **Reconsider when**: The authoritative source or publication mechanism changes.
