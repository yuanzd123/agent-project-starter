# L004 · Isolate the actual test resources

Status, tags, and review dates live in the [registry](../lessons.json).

- **Scope / trigger**: Development servers, seeds, integration tests, simulated clocks, or SDK initialization.
- **Cause**: Configuration loading and SDK defaults may access real data or local login caches.
- **Principle**: Before local commands run, verify resolved databases, accounts, storage, and SDK configuration. Tests must not inherit production side effects.
- **Action**: Use dedicated resources, verify resolved targets, and keep secret values out of logs and committed configuration.
- **Validation**: Test in isolation; inspect resource changes and network destinations when the risk warrants it.
- **Reconsider when**: An SDK, environment loader, or execution entry point changes.
