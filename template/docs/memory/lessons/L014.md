# L014 · Protect invariants during bulk edits

Status, tags, and review dates live in the [registry](../lessons.json).

- **Scope / trigger**: Bulk copy edits, renames, formatting, and migrations.
- **Cause**: Spot checks miss large-diff mistakes, while old snapshots can overwrite someone else's newer work.
- **Principle**: Check numerical, structural, and behavioral invariants. Diagnose unexpected differences and ownership before restoring files.
- **Action**: Define a task-scoped baseline and allowed changes; do not automatically classify every difference as corruption.
- **Validation**: Compare key values, identifiers, structure, or behavior and review each unexpected change.
- **Reconsider when**: The task intentionally changes those invariants; redefine the allowed set.
