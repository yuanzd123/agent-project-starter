# L002 · Match status claims to current evidence

Status, tags, and review dates live in the [registry](../lessons.json).

- **Scope / trigger**: Reporting progress, handing off, or resuming an older session.
- **Cause**: Old tasks and merged code do not establish the state of the current environment.
- **Principle**: Implementation, testing, deployment, enablement, and real use need separate evidence. Resolve conflicts between memory and current observations.
- **Action**: Check relevant code, task results, and environment evidence. Mark unknowns unverified instead of refreshing a date.
- **Validation**: Map each claim to the appropriate evidence; record the information cutoff when remote state is unavailable.
- **Reconsider when**: The relevant revision, environment, or user decision changes.
