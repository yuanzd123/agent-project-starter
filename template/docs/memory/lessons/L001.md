# L001 · One authoritative source per fact

Status, tags, and review dates live in the [registry](../lessons.json).

- **Scope / trigger**: Several agents, worktrees, or entry files repeat the same decision.
- **Cause**: Independent copies let old constraints return or new decisions disappear.
- **Principle**: Keep rules, current state, and durable lessons separate. Tool entry points should reference shared content instead of maintaining drifting copies.
- **Action**: Edit the authoritative record and link to it elsewhere. Keep live status out of navigation files.
- **Validation**: Check links, duplicate records, and the instructions the actual agent loaded.
- **Reconsider when**: Redefine ownership and reconciliation if a new collaboration model needs independent state.
