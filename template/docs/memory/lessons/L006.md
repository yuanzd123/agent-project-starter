# L006 · Verification must preserve failure

Status, tags, and review dates live in the [registry](../lessons.json).

- **Scope / trigger**: Task runners, CI, shell wrappers, and log pipelines.
- **Cause**: Conditional invocation and pipelines can change error propagation; a later success can hide an earlier failure.
- **Principle**: A failed or timed-out required check, missing executable, or missing configuration must never become PASS.
- **Action**: Handle exit status explicitly. Distinguish missing checks from failed checks; label absent validation unconfigured.
- **Validation**: Make an early command fail and a later one succeed; verify nonzero overall status and that later work stops. Test missing commands too.
- **Reconsider when**: The runner, shell, language, or task system changes.
