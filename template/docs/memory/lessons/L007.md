# L007 · Verify the actual execution path at the right depth

Status, tags, and review dates live in the [registry](../lessons.json).

- **Scope / trigger**: Adding integrations, changing schema, or delivering observable behavior.
- **Cause**: Test doubles can bypass the path that fails in the real environment.
- **Principle**: Static checks and mocks establish only their own layer. External dependencies, actual configuration, and user interactions need appropriate runtime evidence.
- **Action**: Choose the smallest meaningful controlled acceptance test. Keep unavailable permissions or devices explicitly unverified.
- **Validation**: Trace an input to an observable outcome and verify which dependencies the test actually exercised.
- **Reconsider when**: An external service or product path changes; small edits do not automatically require full production acceptance.
