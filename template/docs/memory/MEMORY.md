# Shared Memory

This directory holds sanitized, durable engineering knowledge for this project. It is the shared source for every agent.

1. [Current state](LATEST.md): what is actually true and what remains.
2. [Decisions](DECISIONS.md): why a significant choice was made.
3. [Lesson index](LESSONS_INDEX.md): complete navigation, including retired entries.
4. [Import review](IMPORT_REVIEW.md): what was generalized, excluded or deferred.
5. [Workflow](../workflows/project-workflow.md): command configuration and verification boundaries.

Use `python3 scripts/memory.py brief --task "ui review"` for a small relevant selection. Tags include `git`, `testing`, `database`, `cms`, `ui`, `release`, `security`, `memory`, `toolchain`, and Chinese equivalents.

Do not duplicate current state here. Private notes and generated artifacts belong in ignored .local/ or an approved external location. No automatic upload hooks are installed.
